Kallubi Wallet – Linux sandbox

Dev on this Ubuntu machine:
  npm run start:linux-nosandbox

Why: Electron chrome-sandbox needs root-owned 4755 helper.
Without that, Electron aborts. --no-sandbox is the documented fallback.

Optional (this PC only, after every electron upgrade):
  sudo chown root:root node_modules/electron/dist/chrome-sandbox
  sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
  npm start

Packaged AppImage: same FUSE + sandbox issue. Ship with
  ./Kallubi-BSV-Wallet-*.AppImage --no-sandbox
until a signed helper is in the image.

Windows / macOS: use normal start, no --no-sandbox.
